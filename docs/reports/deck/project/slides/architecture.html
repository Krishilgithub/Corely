This is the system in three tiers. At the top, users work in the browser. In the middle is one Next.js server: every request first passes the login and role check, which uses a signed JWT cookie and the role’s permissions. The API routes, highlighted in blue, handle asking, sources, projects and memory. When a source syncs, the ingestion pipeline fetches items from the six connected tools, splits them into chunks, turns them into vectors and tags their projects. At the bottom are the services: Supabase PostgreSQL with pgvector stores everything, including the vectors; Claude writes the answers and extracts memory; and OpenAI makes the search vectors, because Anthropic has no embeddings API. Every table carries a workspace id, so one company never sees another’s data.
