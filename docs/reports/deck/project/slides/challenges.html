Hard problems we solved

AI answers that sound right but are made up

Strict prompt rules, a 0.55 match threshold, and a clear “I don’t know” when nothing matches.

Information that is out of date

A freshness score that drops every day, faster for chat and slower for documents.

Pages failing at random

Traced it to the database pooler’s 15-connection limit and switched to the transaction pooler.

Fake numbers and open API routes

Replaced invented stats with real data, and put a login and workspace check on every route.

Click to reveal each challenge. First, language models can give answers that sound right but are invented; strict rules, a similarity threshold and an honest “I don’t know” fixed that. Second, a correct answer from an old chat may no longer be true, so every source gets a freshness score. Third, pages were failing at random; the server log showed the database pooler allows only 15 connections, so testing moved to the transaction pooler. Fourth, an audit found screens with invented numbers and some API routes anyone could call; we replaced the fake numbers with real data or a clear “coming soon”, and every route now checks the login and workspace.
