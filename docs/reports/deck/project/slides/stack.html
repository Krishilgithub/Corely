Department of Computer Science & Engineering,
Devang Patel Institute of Advance Technology and Research (DEPSTAR)

The frontend and the API live in one Next.js 15 project written in TypeScript. Data is stored in Supabase PostgreSQL; the pgvector extension lets the same database do meaning-based search. Answers come from Anthropic’s Claude: Opus 5.5 by default, and Haiku 5.5 for the faster memory extraction. Search embeddings still come from OpenAI, because Anthropic does not offer an embeddings API. Prisma handles database access, Zod checks request data, and security uses signed JWT sessions, bcrypt password hashes and AES-encrypted connector tokens. The app is packaged with Docker.
