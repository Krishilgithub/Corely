What we built

Six features that make it useful

Ask Corely

Answers stream in word by word, with numbered citations.

Freshness score

Each source loses points daily, so old facts are flagged.

Organisation memory

Decisions, risks, milestones and facts, kept by AI.

Projects

One view per project across all tools, with its own Ask.

Roles and permissions

Every API route checks the login, role and workspace.

Six connectors

Slack, Notion, Drive, Gmail, GitHub and Linear.

Department of Computer Science & Engineering,
Devang Patel Institute of Advance Technology and Research (DEPSTAR)

These are the six main features. Ask Corely is the core: answers stream in and cite their sources. The freshness score drops every day, faster for chat and slower for long documents, so users know when information is old. Organisation memory keeps decisions, risks, milestones and facts. Projects group documents and memory by project across every tool, and each project has its own Ask. Roles and permissions protect the data: every API route checks who is logged in and which workspace they belong to. Finally, six connectors bring the data in, plus PDF and Word upload.
